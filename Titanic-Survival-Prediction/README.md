# Titanic Passenger Survival Prediction

This project predicts Titanic passenger survival using a machine learning model.

## Files
- `app.py` — Streamlit application
- `requirements.txt` — Required Python libraries
- `svc_trained_model.pkl` — Trained machine learning model
- `sample-data.csv` — Sample dataset
- `Titanic_Passenger_Survival_Recommended.ipynb` — Jupyter notebook
